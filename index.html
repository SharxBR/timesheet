Set up encrypted cloud sync

One-time setup. Do this once per device. Your bank data is scrambled on this device before it ever leaves — the cloud only stores an unreadable blob.

Step-by-step: get your GitHub token & Gist ID (click to expand)

A. Create a free GitHub account at github.com/signup if you don't have one.

B. Make a fine-grained token that can ONLY touch gists:

  1. Go to Settings → Developer settings → Fine-grained tokens → Generate new.
  2. Name it timesheet-sync, set an expiry (e.g. 1 year).
  3. Under Account permissions, find Gists and set it to Read and write. Leave everything else as "No access".
  4. Click Generate token and copy the github_pat_... value.

C. Create the secret Gist that will hold your encrypted data:

  1. Go to gist.github.com.
  2. Filename: timesheet-data.json, content: just type {}.
  3. Click Create secret gist (the dropdown next to the button).
  4. Copy the Gist ID from the URL — it's the long code after your username, e.g. gist.github.com/you/abc123def456.

D. Paste both below, pick a passphrase, and click Connect. On your phone and other computers, use the same token, Gist ID, and passphrase.
